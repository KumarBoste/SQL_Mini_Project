# E-Commerce Sales & Customer Analytics Using MySQL (2026)

## Project Overview
This project analyzes a simulated e-commerce business using MySQL 8.0+. It explores customer behavior, product performance, order trends, payment transactions, inventory levels, and delivery performance.

## Objectives
- Design a relational database using primary and foreign keys.
- Analyze sales and customer purchasing behavior.
- Apply SQL joins, aggregate functions, subqueries, CTEs, and window functions.
- Measure order status, payment performance, and inventory risks.
- Develop reusable views and improve query performance with indexes.

## Technologies
- MySQL 8.0+
- MySQL Workbench
- SQL

## Dataset
Five related tables: customers, products, orders, order_items, and payments. Each table contains fewer than 50 sample records.

## Skills Demonstrated
Database design, data manipulation, data aggregation, multi-table joins, ranking, running totals, moving averages, customer segmentation, sales analysis, and transaction management.

## Business Value
The analysis framework can help a business identify valuable customers, evaluate product sales, monitor payment outcomes, detect low inventory, and assess delivery performance.

## Disclaimer
All sample data is synthetic and intended for educational and portfolio use.
